Clause order

        
    
          
  1. WITH
  2. SELECT
  3. FROM
  4. JOIN … ON
  5. WHERE
  6. GROUP BY
  7. HAVING
  8. ORDER BY
  9. LIMIT
    10. 
        

        
Write them in this order. The database evaluates them as FROM/JOIN → WHERE → GROUP BY → HAVING → SELECT (window functions run here) → ORDER BY → LIMIT. That's why WHERE can't use an aggregate or a window function, and HAVING can use an aggregate.
