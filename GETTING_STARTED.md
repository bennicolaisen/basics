# Getting Started

1. **Install once, if you don't have them:** Java 17, Maven, Python 3.10+,
   and IntelliJ IDEA (Community is fine).

2. **Clone the repo:**
   ```bash
   git clone https://github.com/bennicolaisen/basics.git
   ```

3. **Open it in IntelliJ:** `File > Open...` → select the `basics` folder
   you just cloned (the one with `pom.xml` in it). When IntelliJ asks to
   **"Load Maven Project,"** say yes — that pulls in all the Java weeks at
   once.

4. **Start at the top:** open `README.md` and read the syllabus. Then go
   to `Month-1-Python-Foundations/Week-01-unit-converter-toolkit/` and
   read *its* `README.md` — that's lesson one.

5. **Run a week's tests to check it works:**
   - **Python weeks (1–9 and 19–26):** open a terminal in that week's
     folder and run `python -m pytest -q` (first time only:
     `pip install pytest`).
   - **Java weeks (10–17):** pick `Week NN - Run Tests` from the Run
     Configuration dropdown at the top of IntelliJ and click ▶.

6. **Work through it in order**, one week at a time, using the table in
   the root `README.md` as your map. Each week's README ends with a
   "Try It Yourself" section — that's your actual homework once the
   lesson makes sense.

Stuck, or IntelliJ isn't cooperating? See `INTELLIJ_SETUP.md` for more
detail.
